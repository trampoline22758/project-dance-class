# AGENTS

## Overview
This repository contains the static website for Miss Kim's Dance Class. Pages are plain HTML, CSS, and minimal JavaScript.

## Development Guidelines
- Use 4 spaces for indentation in HTML, CSS, and JS files.
- Keep line lengths under 120 characters.
- Favor semantic, accessible markup (skip links, alt text, ARIA labels).
- Commit compiled/static assets directly; no build tools or frameworks.
- Keep filenames lowercase and hyphenated.

## Testing
- Run `npm test` after making changes to ensure the Node environment works.
- Manually verify HTML pages in a browser when modifying markup or styles.

## Project Structure
- Top-level directory contains individual HTML pages.
- Shared styles live in `styles.css`.
- Images and other assets reside in `photos/` and related folders.
